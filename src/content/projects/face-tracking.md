## 개요

PC가 웹캠 영상에서 YOLOv8로 사람을 찾고, face_recognition으로 등록된 인물인지 확인합니다. 등록 인물의 얼굴 중심이 화면 중앙에서 얼마나 벗어났는지(픽셀 오차)를 USB 시리얼로 Arduino에 보내면, Arduino가 상하·좌우 서보를 움직여 대상을 화면 중앙으로 따라갑니다. 3초 동안 조준이 유지되면 세 번째 서보가 트리거 동작을 합니다.

조이스틱으로 직접 조작하는 수동 모드와 영상 인식 자동 모드가 있고, 버튼을 길게 눌러 전환합니다.

## 시스템 구조

```
웹캠 → PC (YOLOv8 사람 탐지 → face_recognition 인물 확인 → 중심 오차 계산)
     → USB 시리얼 9600bps ("오차X,오차Y" / "SHOOT" / "LOST")
     → Arduino Uno → 서보 3개 (상하 · 좌우 · 트리거)
```

## 내가 맡은 일

- Arduino 제어 로직 전체: 시리얼 명령 파싱, 상대 각도 제어, 수동/자동 모드 전환
- 서보 3개와 조이스틱을 연결한 하드웨어 제작

## 기술적 고민과 해결

- **서보 떨림:** 작은 오차에도 서보가 계속 움직여 떨렸습니다. 영상 쪽은 ±30px, 조이스틱은 ±50 범위를 데드존으로 두고 그 안의 변화는 무시했습니다.
- **부드러운 추적:** 목표 각도를 한 번에 쓰지 않고, 현재 각도에 오차에 비례한 변화량(-5~+5도)을 더하는 상대 각도 방식으로 바꿨습니다. 각도는 0~180도로 제한했습니다.
- **통신 방식 변경:** 처음엔 블루투스(HC-06)를 썼지만 macOS 호환성 문제와 서보 라이브러리 충돌이 있어 USB 유선 시리얼로 바꿨습니다.
- **버튼 하나로 두 기능:** 길게 누르면(0.5초) 모드 전환, 짧게 누르면 트리거 동작이 되도록 입력을 구분했습니다.

## 결과

- 200회 인식 테스트에서 등록 인물 98/100회, 미등록 인물 97/100회 정확 판별 (오판율 3% 미만)
- 트리거 명령 전송과 서보 동작은 테스트에서 모두 정상 동작

## 개선할 점

- 0.5m/s 이상 빠르게 움직이는 대상은 추적이 늦어집니다. 오차 크기에 따라 변화량을 키우는 방식이 필요합니다.
- 화면에 여러 명이 있으면 얼굴 비교 연산이 늘어 프레임이 떨어집니다. 중앙에 가까운 대상부터 처리하는 우선순위가 필요합니다.
