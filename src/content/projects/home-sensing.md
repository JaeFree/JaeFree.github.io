## 개요

IoT 캡스톤디자인에서 만든 비접촉식 고독사 방지 시스템입니다. Arduino Mega는 온도·습도·유해가스를, Arduino Uno는 움직임·문 열림·응급 버튼을 감지합니다. 두 보드가 블루투스로 라즈베리파이에 데이터를 보내면, 라즈베리파이가 이를 해석하고 기록해 5초마다 ThingsBoard 대시보드로 올립니다.

## 시스템 구조

```
Arduino Mega (DHT11, MQ135, 서보) ──BT──┐
                                         ├→ Raspberry Pi (파싱 · 로그) → ThingsBoard
Arduino Uno (PIR, 문 센서, 응급 버튼) ─BT─┘
```

## 내가 맡은 일

- Arduino 센서 수집·제어 코드
- 라즈베리파이에서 두 보드의 블루투스 데이터를 받아 해석하는 Python 코드

## 기술적 고민과 해결

- **두 장치 동시 수신:** 장치마다 스레드를 따로 두고, 연결이 끊기면 5초 뒤 자동으로 다시 연결하게 했습니다.
- **잘려서 오는 데이터:** 블루투스는 한 메시지가 여러 조각으로 올 수 있어, 줄바꿈이 나올 때까지 버퍼에 모은 뒤 한 줄씩 해석했습니다. 스레드끼리 같은 데이터를 쓰기 때문에 Lock으로 보호했습니다.
- **메시지 형식 설계:** 환경 데이터는 `온도,습도,가스`를 2초마다, 활동 데이터는 `움직임,문`을 상태가 바뀔 때만 보내 통신량을 줄였습니다. 응급 버튼은 `EMERGENCY` / `SAFE`로 따로 보냅니다.
- **이벤트 기록:** 문이 닫힘에서 열림으로 바뀐 순간과 응급 상태 변화를 시간과 함께 파일에 남겼습니다.

## 결과

- RGB LED로 현장 상태 표시: 파랑 문 열림, 초록 활동 중, 빨강 10초 이상 움직임 없음
- 유해가스 수치가 기준을 넘으면 서보 동작
